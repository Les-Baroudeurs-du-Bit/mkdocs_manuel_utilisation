    Bienvenue sur le manuel utilisateur.

    Bienvenue à vous les tripeurs !

    Pour commencer, il vous faut vous connecter à votre application. Si vous avez un compte, vous pouvez vous connecter, sinon, veuillez cliquer sur “s’inscrire”.

    La page qui s’affiche vous propose plusieurs champs à remplir:

    • votre pseudo qui sera le nom avec lequel l’appli vous appellera
    • votre identifiant, mail ou nom d’utilisateur, qui servira à se connecter au compte
    • un mot de passe pour sécuriser le tout

    Une fois connecté, vous vous retrouverez sur le tableau de bord, qui représente votre page principale. Lors de votre première connexion, cette page n’affiche qu’un bouton. En haut à gauche vous trouverez un menu Burger ≡ qui vous permettra d'accéder aux autres fonctionnalité de l’application.

    Mes road Trip
      Cette page vous permet d’enregistrer vos roadtrip. Vous pouvez en ajouter en cliquant sur le bouton rouge Créer un road trip. Dedans, vous pouvez lui donner un nom ainsi qu’une date de début et de fin. Une fois enregistré, la page des road trip vous l'affiche et vous pourrez donc interagir avec pour le modifier ou le supprimer. Si vous cliquez sur votre roadtrip, la page vous affichera les jours de votre roadtrip avec les étapes et l’hébergement lié au jour.
      Page étapes de la journée   Accessibilité :
             mes road trip > le road trip > le jour > (vous êtes sur la page)
              tableau de bord > le jour > (vous êtes sur la page)
        Lorsque vous avez créé un roadtrip, celui-ci est découpé en journée. Chacune de vos journées est ponctuée par des étapes et un hébergement pour la nuit. Vous pouvez donc sur cette page ajouter un hébergement sans avoir à y aller avec le menu burger. Vous pouvez aussi ajouter des étapes (ex: aller voir mamie…) avec un nom, une localisation, un commentaire et lui affecter sa journée.
    Mes réservations
      Cette page vous permet d’enregistrer vos hébergements. SI vous avez déjà enregistré un hébergement, vous pouvez interagir avec pour le modifier ou le supprimer. Si vous voulez en ajouter, cliquez sur le bouton pour arriver sur la page d’enregistrement.
      Page d’enregistrement des hébergement   Accessibilité :
             tableau de bord > Ce soir : … > (vous êtes sur la page)
              tableau de bord > le jour > ajouter un hébergement >(vous êtes sur la page)
        La page d’enregistrement vous permet d’ajouter le nom de l'hôtel, son adresse, la date d’arrivée liée avec le nombre de nuit (qui vous permet de calculer la date de départ automatiquement). Vous pouvez ajouter une heure d’arrivée si vous en avez une, le numéro de téléphone de l'hôtel ou encore des documents en lien avec la réservation. La dernière case vous permet d’afficher visuellement si votre hébergement à été payé ou non, pour vous permettre de savoir rapidement.
    Tableaux de bord
      Cette page vous permet d'accéder facilement à votre roadtrip en cours. Il vous affiche chaque jour avec ses différentes activités, il vous permet aussi d'accéder rapidement aux détails de chaque étape qui constitue votre journée.
      Le bouton Naviguer vous permet d’ouvrir l’application maps en vous proposant un itinéraire par rapport à votre position et celle de votre prochaine activité (si vous avez renseigné sa ville ou localisation précise)
      Le bouton Voir le détail de l’étape est explicite, il permet d'accéder aux détails de l'étape et permet aussi de modifier le commentaire en lien avec cette étape.
      En dessous, vous pouvez voir le programme du jour, avec le bouton y aller qui à la même fonctionnalité que Naviguer. La flèche v vous permet d’afficher les commentaires (la zone est modifiable)
    Mon compte
      Vous permet de gérer votre compte et de vous déconnecter de l'application. Vous pourrez ajouter une photo, changer votre pseudo, votre email ainsi que votre mot de passe. Bien évidemment, vous pourrez aussi supprimer votre compte utilisateur si vous ne le voulez plus.
